# MiniMax-H3 V2 工作流验证记录

## 当前范围（2026-09-21 本地视频引用增量）

- 新 MiniMax-H3 任务固定 V2，参数面板不显示接口版本；V1 兼容常量和版本解析保留，不作为本轮验收路径。
- 提示词增强默认关闭。开启后先增强，成功后自动生成视频，无独立审阅弹窗或复制到画板步骤。
- 主输入栏按界面语言在 Context IR 文本末尾附加语言指令，中文为“请用中文输出”；不转换结果、不增加 language 请求字段。语言遵循情况由上游模型决定。
- 已完成、具有有效远端 ID 的 MiniMax-H3 768P 视频可升 2K；2K、其他分辨率、未完成、缺少或空白 ID 在 UI 和业务层拒绝。
- 历史 1280x720 / 720x1280 参数按 H3 原请求的默认 768P 兼容。
- 不限制 Key 分组，不自动切换供应商。增强使用当前供应商，重制保留源任务路由。
- 任务队列进度与终态回写保留 remoteId、invocationRoute，避免刚生成的视频丢失升 2K 所需信息；不恢复已丢失的历史 ID。
- 主输入栏的视频模式可选择或拖入本地视频，素材库仅显示图片和视频；H3 最多接受 3 个视频引用，其他不支持模型继续走既有能力校验。
- 本地 `/asset-library/` MP4/MOV 在请求时从缓存转换为 Data URL，公网 HTTP(S) 视频尝试读取并转换，读取失败或类型不匹配时保留原地址。工作流不持久化 Base64。
- 考虑 Base64 膨胀，本地 H3 参考视频合计限制为 47 MiB，完整 JSON 请求体限制为 64 MiB；更大视频需使用公网 URL。

## 接口

- 普通生成：POST /v2/video_generation。
- 提示词增强：POST /v2/h3_context_ir，model=MiniMax-H3，发送 content、duration、ratio，不发送 resolution；完成后读取 task.content.prompt。
- 重制：POST /v2/video_regeneration，仅发送 model=MiniMax-H3、source_task_id、resolution=2K。
- 统一查询：GET /v2/query/video_generation/{task_id}。
- 参考视频：content[].video_url，role=reference_video；支持 MP4/MOV，最多 3 个。缓存缺失、格式错误、非公网地址、本地视频合计超过 47 MiB 或完整请求体超过 64 MiB 时，不发送供应商请求。
- HTTP 错误、非零 base_resp.status_code、任务失败/取消、缺失任务 ID 或增强结果均终止；增强轮询有次数上限，不在失败后提交视频。
- 源任务是否归属当前账号、是否有效及是否超过保留期限由服务端校验；不能用本地资格检查证明上游可接受。
